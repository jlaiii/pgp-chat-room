PGP Room

End-to-end encrypted rooms. Messages are encrypted and signed in your browser, and the server only ever stores ciphertext.

Your password signs you in. Message encryption uses a key made in this browser, so the server still cannot read anything you send.

Guests can read and post in public rooms. No account, no rooms of your own, nothing tracking you beyond an anonymous handle.

    Your key is made for the account and stays with it — it cannot be detached or left unsaved, and every device you sign in on uses this one key. The envelope on the server is sealed with your password; the backup file below is the copy nothing else can take away.

    Replacing the key is deliberate: a new key is generated here, the old one is erased from the server in the same step, and messages sealed to the old key stop opening for you. Everything else about the account stays.
